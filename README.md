# JobKit 求职定制工作室

按一份真实经历和一份目标岗位 JD，交付可以继续编辑、打印和面试复盘的求职材料。不是简历模板订阅，也不虚构经历或承诺录用。

## 两个固定套餐

| 套餐 | 价格 | 交付 |
|---|---:|---|
| 岗位定向基础包 | ¥39 | 简历源稿、HTML、A4 PDF、Word、求职信、面试卡、岗位匹配报告、确认单 |
| 面试证据链冲刺包 | ¥99 | 基础包全部内容，加主张证据表、定向回答草案、7 天投递计划 |

资料完整后 24 小时交付初稿；均含一次原范围修订。

## 交付如何验收

每个订单 ZIP 包含 `DELIVERY.json`，记录套餐、文件清单、验收项和每个文件的 SHA-256。客户投递前应核对姓名、联系方式、时间、经历与所有数字。

## 服务边界

- 只整理客户有权使用的真实资料。
- 不伪造学历、任职、项目、证书或业务数据。
- 不要求身份证、银行卡、账户密码等无关敏感信息。
- 不承诺 ATS、面试、薪资或录用结果。
